# Enterprise Network Lab

This repository contains enterprise networking labs and troubleshooting practice for Network Engineer roles.

## Technologies

* VLAN
* Inter-VLAN Routing
* OSPF
* NAT
* ACL
* IPSec VPN
* STP
* EtherChannel

## Tools

* PNETLab
* Cisco IOS
* Fortigate
* Packet Tracer
* Wireshark

## Objectives

* Practice enterprise network deployment
* Improve troubleshooting skills
* Understand routing and switching
* Learn enterprise network flow

## Current Labs

* VLAN Basic
* Inter-VLAN Routing
* Static Routing
* OSPF Basic
